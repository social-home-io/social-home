How prominent should the transport signal be in the connection card?

Four variants of the same connection card. Each shows the same peer ("Bob (Beta House)") in three transport states: fast (WebRTC DataChannel open), fallback (HTTPS-only — works but higher latency), and unreachable. Pick the variant that feels right; we'll iterate on the words and detail-view after.

A

Color-coded dot + tooltip

Reuses the existing status-dot slot. Green = fast (WebRTC), blue = fallback (HTTPS), red = unreachable. Hover or focus reveals a tooltip: "Connected directly (low latency)" / "Via cloud relay (higher latency)". Zero new layout — just an extra colour meaning. Risk: colours alone can't carry meaning for colour-blind users without the tooltip.

Bob (Beta House) Household
Carol (Gamma House) Household
Dave (Delta House) Household Unreachable
B

Inline glyph after the name

A tiny lightning bolt (⚡ = direct), cloud (☁ = relay), or warning (⚠) sits right next to the display name. Status dot stays binary (reachable / not). Glyph carries the transport story. Good glanceability; works without colour. Risk: emoji rendering varies by OS, and the glyph crowds the name slightly.

Bob (Beta House) ⚡ Household
Carol (Gamma House) ☁ Household
Dave (Delta House) Household Unreachable
C

Transport pill alongside the type badge

Adds a second small pill next to the existing "Household" badge: green "Direct" pill for WebRTC, amber "Cloud" pill for HTTPS. Explicit, accessible (text + colour), and matches the existing badge vocabulary. Risk: visual weight — every card grows one chip wider.

Bob (Beta House) Household Direct
Carol (Gamma House) Household Cloud
Dave (Delta House) Household Unreachable
D

Asymmetric: show only the unusual state

Direct (the healthy, expected case) shows nothing extra — same card as today. The card surfaces a label only when something is off the happy path: amber "Via cloud" for HTTPS-only peers, red "Unreachable" for offline. The fast state is silent; the dashboard only ever calls attention to peers that need attention. Lowest visual cost when everything's healthy. Risk: users can't easily tell the difference between "WebRTC working" and "we haven't determined the transport yet".

Bob (Beta House) Household
Carol (Gamma House) Household Via cloud
Dave (Delta House) Household Unreachable
